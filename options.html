📖 使用说明

1. 获取API Key

  • OpenAI: 访问 https://platform.openai.com/api-keys
  • DeepSeek: 访问 https://platform.deepseek.com/
  • 豆包: 访问 https://console.volcengine.com/ark

2. 使用插件

  1. 在支持的AI对话页面（豆包、DeepSeek等）
  2. 用鼠标框选想要解释的文本
  3. 点击旁边出现的🤖图标
  4. 等待AI解释结果在弹窗中显示

3. 注意事项

  • API Key仅保存在您的浏览器本地，不会上传到任何服务器
  • 每次解释会消耗您的API额度，请注意使用
  • 建议使用GPT-3.5或DeepSeek Chat以节省成本
